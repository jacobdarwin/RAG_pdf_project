# RAG PDF Chatbot

A production-style RAG application that answers questions from uploaded PDF documents using semantic search and LLMs.

## Features

- PDF Upload
- Semantic Search
- ChromaDB Vector Store
- HuggingFace Embeddings
- Groq LLM Integration
- Streamlit UI

## Tech Stack

- Python
- LangChain
- ChromaDB
- HuggingFace
- Groq
- Streamlit

## Run Locally

pip install -r requirements.txt

streamlit run app.py
